CÁCH MỞ BẢN LOCAL

1. Nhấp đúp START_APP.bat.
2. Giữ cửa sổ Local Server đang mở trong lúc dùng app.
3. App sẽ tự mở trong trình duyệt tại địa chỉ http://127.0.0.1 với một cổng trống.
4. Khi dùng xong, đóng cửa sổ Local Server hoặc nhấn Ctrl+C.

Không mở trực tiếp index.html bằng file:/// vì Chrome chặn JavaScript module và PDF worker.
